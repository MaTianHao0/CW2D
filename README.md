# CW2D
“CW2D”插件电池是一款基于Rhino中Grasshopper开发的插件，具有高效、稳定且易用的三维转二维施工图纸功能，以优化设计流程、提高工作效率，如图1所示。

图1 CW2D插件电池
CW2D电池整体根据功能可分为两大类，功能电池，出图电池。功能电池可分为构件库属性电池、绑定属性电池、填充图案电池、图框电池、标注电池；出图电池依据不同施工图类型可分为，平面图、立面图、剖面图、大样图、节点图；
一、功能电池
CW2D的功能电池包括“构件库属性”电池及“绑定属性”电池，其中“构件库属性”电池用于对材料信息的增添和修改。点选“构件库属性”电池后，点击“添加属性”，可进行构件库信息的选择，如图1-1和图1-2所示。
1.构件库属性
例如选取玻璃属性，点击“+”，再点击“面板”，即可展示玻璃构件信息；点击“构件库”可打开对应的CSV文件进行材料信息的增删改，若没有CSV文件则会自动新建，保存信息后关闭即可，此处确保CSV文件名称与“类型”名称对应，即“类型”与显示的名称应对应，否则不显示材料信息，点击“更新数据”可同步CSV文件到显示界面上，如1-3所示。
在构件库电池中，可以设置剖面填充样式、立面填充样式、图样表示、标注、门窗等信息。需要注意index.json文件需要放置在指定目录"..\Plug-ins\Grasshopper\Components\index.json"下，电池才可正常运行。

7.图框电池
CW2D插件电池包括“图框”电池，用于导入图框。其中右键整个电池->Settings打开图框电池设置面板，点击“浏览”设置模板路径并将模板放置在路径下，点击“测试路径”可检查是否配置正确，点击“图框信息设置”可设置图框文本内容，如如图1-8和图1-9。
“图框”电池的输入部分包括，“BP”(Base Point)接收Point类型的输入，用于定位图框的左下角，“S” (Frame Size)接收Text类型的输入，内容必须为“A1”“A2”“A3”“A4”“A5”之一，确保输入的信息与图框电池设置面板中信息一致，如A3；“G”（Generate）接收Boolean类型的输入，用于控制是否生成图框。
输出部分包括，C(Frame Curves)为Curve类型信息，此接口仅输出图框中的线框；T（Text Objects）为Text文本类型，此接口仅输出图框中文本内容；G(All Geometry)为Geometry类型，此接口输出图框内的所有信息，在Geo中右键bake即可将图框信息导入到Rhino中，如示图1-10。
在使用中，会出现字体过大问题，此时按照图1-11所示，接入“scale”电池缩放即可正常输出。

10.图层电池
本组件用于按图层读取 Rhino 场景中的对象信息。使用时，先在“运行”接口保持为 false，等参数设置完成后再切换为 true 以开始执行；在“层名”接口中输入目标图层名称，输入 all 时会扫描所有图层，也可以通过逗号或多行一次写入多个图层名。在实际使用中，需要保证 Rhino 中有已打开且激活的文档，否则组件无法正常获取对象。建议手动控制“运行”接口，避免持续为 true 导致频繁重复计算并拖慢文件。
在“层名”输入端上右键并启用 Collection 后，可以让该输入一次接收多个文本项，即多个图层名称，组件会将这些名称视为一组目标图层，逐一解析并合并所有结果一起输出。即便不特别开启 Collection，只要连接的 Panel 中写入多行文本或使用逗号分隔多个图层名，同样可以实现一次处理多个图层，从而方便对不同图层进行批量统计和信息提取。（图1-16）

12.立面图标注（标高）
本组件用于根据给定的基准线和标注点，自动生成立面标高标注。使用时，在“标注点”输入端接入一个或多个需要标注的位置点；在“基准线”输入端输入一条作为标高参考的线，组件会根据标注点到这条基准线的距离生成对应的标高数值；“偏移”用于控制标高符号相对标注点的水平偏移距离；“缩放”用于整体控制标高符号和文字的大小，默认值为 1.0。缩放值越大，输出的符号和文字也会相应变大，便于适配不同比例的图纸或模型显示。
组件输出端“标高”会统一输出生成后的全部几何，包括标高符号线、折线符号以及数字文字对象。这些结果可以直接预览，也可继续用于后续整理或烘焙到 Rhino 中。本组件适合用于建筑立面、剖面或其他需要快速表达高度信息的场景，可减少手动绘制标高符号和输入数值的重复操作。

图 1-18 标高展示
13.轴线标注
本组件用于为一组平行轴线快速生成轴线标注，并自动在每条轴线两端添加圆圈字母编号。使用时，在“轴线”输入端接入至少两条平行曲线；在“标注基准点”输入端输入一个或多个点，这些点决定标注线经过的位置，因此可以用来控制标注布置在轴线的哪一侧或哪几个位置。“标注字高”用于控制标注文字大小，默认值为 3.5；“标注平面”用于指定标注所在平面，默认为 XY 平面。组件会根据输入轴线的方向和标注平面自动生成相邻轴线之间的尺寸标注。
除了轴间尺寸标注外，组件还会按照轴线输入顺序，自动为每条轴线添加字母编号，如 A、B、C，并分别放置在轴线两端的圆圈中，便于直接用于轴网表达。编号顺序与轴线的输入顺序一致，因此建议按图纸阅读习惯整理轴线顺序后再输入，这样输出结果会更清晰。
使用时需要注意，“轴线”数量不能少于两条，否则组件无法生成标注。为了获得较好的结果，建议输入的轴线尽量保持平行且方向一致；“标注基准点”应尽量放在希望标注线经过的位置附近，以便得到更符合预期的标注效果。

4)大样图排版
“大样图排版”电池的“主视图”接口，“下部视图”接口和“右部视图”接口接收曲线、标注、剖面线类型。如果想将多个图形作为整体被电池接收进行排版，需要使用grasshopper自带的Entwine电池，把每个图形都接入Entwine电池的同一个接口，把Entwine电池的输出结果连接至电池对应输入接口即可；“垂直间距”接收Number类型的输入(默认为0.1)，代表的是实际垂直间距和主视图的高度的比值，控制图之间的垂直间距；“水平间距”接收Number类型的输入（默认值为0.1），代表的是实际水平间距和主视图的宽度的比值，用于控制图之间的水平间距；“旋转”接收Bool类型的输入（默认值为true），控制是否要将下部视图顺时针旋转90度。电池在主视图位置输出三个视图的排版结果。电池输出剖面线，标注和曲线。如图2-11所示。
